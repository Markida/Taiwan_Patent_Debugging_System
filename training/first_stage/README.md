# 第一階段：黃金驗證集與推論優化

`training/gold_validation_v1` 是從公司核准案件 corpus 中原先完全未參與訓練的
172 張 holdout 頁面凍結而成。用途僅限模型評測，禁止複製到任何訓練資料集。

## 人工檢核

雙擊專案根目錄：

```text
Annotate_Gold_Validation.bat
```

既有模型框只是綠色起點。每頁都必須：

1. 刪除小圓圈、圖線、箭頭及其他非字元框。
2. 補上漏掉的數字、大小寫字母及 prime。
3. `211` 分成 `2 + 1 + 1`。
4. `VIII` 分成 `V + I + I + I`。
5. `7'` 分成 `7 + prime`。
6. 完整檢查後按 `Ctrl+Enter` 完成本頁。

切頁安全規則：

- `上一頁 (PgUp)`、`下一頁 (PgDn)`只會保存目前草稿並移動一頁，不會把草稿標成完成。
- 「指定頁碼／跳至頁面」可隨時返回任意一頁修改，包含已完成頁面。
- 修改任何框時，該頁會自動回到未完成狀態；再次逐一檢查後才按 `Ctrl+Enter`。
- 第一頁與最後一頁不會循環跳轉，避免意外跨到資料集另一端。

可隨時雙擊 `Check_Gold_Validation.bat` 查看剩餘頁數與類別覆蓋率。

黃金驗證集全部完成後，才會執行 confidence／NMS、切片推論及雙模型聯集的
正式比較，避免用未完成標註得到誤導性結論。

## 172 張黃金集的第一階段結論

人工檢核完成後共有 6,782 個字元框，可組成 3,107 個完整標號。頁面 162、
173、174 已依人工判定排除；原始 corpus 圖片仍保留，只有黃金驗證集副本與
標註紀錄被移除。

端到端比較（IoU 0.30，實際執行 EasyOCR）：

| 推論方式 | 顯示結果 | 正確結果 | 精確率 | 召回率 | F2 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 舊正式值：全圖 0.25 / NMS 0.40 | 2,732 | 2,290 | 83.82% | 73.70% | 75.53% |
| 全圖 0.08 / NMS 0.30 | 3,169 | 2,435 | 76.84% | 78.37% | 78.06% |
| 全圖 0.08 + 切片 0.08 | 4,199 | 2,777 | 66.13% | 89.38% | 83.51% |
| **全圖 0.08 + 切片 0.25** | **3,606** | **2,764** | **76.65%** | **88.96%** | **86.19%** |

正式推論採用最後一組：完整標號定位器先做一次全圖推論，再做 2×2 重疊切片；
切片新增框使用較嚴格的 0.25，最後以 NMS 0.30 合併。這組相對舊正式值多找回
474 個正確標號，而精確率下降幅度受控。切片只套用至完整標號 ONNX 模型，
不改變 v1／v2／v3 字元模型的推論方式與門檻。

英文字母、小寫與 prime 的自然樣本仍偏少；目前結論對數字與多字元標號最可靠，
稀有字元須在後續以獨立 challenge set 補驗，不能只用本黃金集推定所有字元表現。

評估報告位於 `models/gold_group_*.json`，其中正式建議值的完整端到端結果為
`models/gold_group_sliced_ocr_slice025.json`。
