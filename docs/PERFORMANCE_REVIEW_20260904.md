# Saint-Island Patent MDS 效能與穩定性檢查（2026-09-04）

## 範圍

以目前工作區最新台陸轉換版本為基礎。保留既有未提交修改，不變更模型、OCR門檻、專利檢核条件、台陸辭典順序或轉換規則；未升版本、未製作安裝包、未發布 GitHub。

## 本輪已實作

### 開啟與正式功能

- 主視窗的 workflow 型別註記不再提前載入整套文件規則。
- 首次開啟圖式標號頁不再先載入 OpenCV、Torch 或 PDF 引擎；真正執行時才載入。
- 文件解析、共用規則讀取、白名單讀取、文字檢核與符號擷取移至背景。視窗維持回應，Esc 可取消結果交付。
- 規則初始載入改為背景執行，保留每次開啟及檢核會讀最新規則的功能。自訂規則管理視窗的讀寫也不阻塞主視窗。
- 每頁最多一個文件/PDF工作；忙碌時防止重複送出。取消不會讓舊結果覆蓋目前文件。
- PDF每次匯入使用獨立輸出目錄，取消或同名PDF不會覆寫先前已校正的圖片；PDF控制代碼在失敗與取消時也會關閉。
- OCR關閉不再銷毀執行中的QThread；背景模型呼叫採合作式取消，晚到進度、錯誤與結果不會重新改動畫面。
- OCR終態尚在GUI佇列時仍維持忙碌，避免再次啟動或匯入造成結果混用。
- 同張圖切換標號重用原始高解析度影像；重新匯入來源會清除快取，避免預覽舊圖。
- 重畫框線只複製當前圖片資料，不再深複製所有頁面的辨識結果。
- 文件錯誤表格批次建立、共用段落索引，避免每條錯誤重新建立整份文件索引；統計不再為了計數序列化整份報告。
- 正式功能的相同修正也用於標準隔離版本；其產生器包含新的共用背景模組與關閉清理流程。

### 台陸轉換

- Word讀取、轉換預覽及紅字差異計算改為背景工作。
- 快速切換來源/範本時，單工合併為最新請求；過期結果不會覆蓋新檔或人工修訂。
- 完全相同的段落直接產生等價HTML，不跑昂貴的逐字差異比對。
- 預覽更新後「一個」檢查側欄只做一次全文扫描；選取條目不再重複序列化全文。
- 字典讀取、上傳及輸出不使用可能在關閉時崩潰的長時間QThread；關閉頁面不等待離線分享。

### 完整版本背景通訊

- 工作頁背景監控只查訊息，不重複掃描排行、表情、已讀或在线名單。
- 訊息維持每秒更新；永久排行以5秒更新，按檔案版本快取歷史JSON。重新進入時仍重新載入近兩天訊息。
- 使用者暱稱/頭像改變即發布，未變動時降低重複寫入頻率。
- 圖片載入工作惰性啟動，連續多張圖片完成合併重畫，不每張重建整個訊息區。
- 慢SMB時不重複產生讀取工作；關閉不再同步等待1.5秒。

## 驗證與邊界

針對慢讀取、取消後的晚到結果、快速切換來源、關閉中的工作、PDF輸出權限錯誤、白名單更新、重複OCR啟動、重新匯入同路徑圖片、正式隔離版shutdown等建立回歸測試。

- 完整 unittest：603項全過（25.992秒；測試耗時不代表單一功能耗時）。
- 主程式 `--gui-smoke-test`：正常啟動並結束，exit code 0。
- `--offline-self-test`：PASS，正式ONNX定位器及本地OCR模型均可載入並執行CPU推論。此為執行環境測試，不是辨識準確率評估；合成圖的偵測數為0，不能宣稱本輪提高模型準確率。
- 自測報告：`.qa/performance_offline_self_test_20260904.json`。

仍不能宣稱所有卡死bug已永久消失：

- 尚未在實際公司SMB斷線、防毒掃描與不同DPI/硬體條件下做現場壓力測試。
- Windows檔案I/O或模型內部的单次native呼叫不保證立即接受取消；本輪採保留GUI回應、丟棄取消後結果，沒有強制terminate工作執行緒。
- 持續未返回的I/O會使該單工保持忙碌，但不會阻塞首頁及其他功能；需要可強制回收的硬逾時時，後續應評估獨立子程序。
- 大型PDF仍須實際轉圖，大型模型仍須首次載入；本輪不以降低畫質、修改模型或放寬辨識門檻換取速度。
