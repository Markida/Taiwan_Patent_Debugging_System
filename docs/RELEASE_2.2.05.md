# v2.2.05 / v2.2.05c 發布進度

## 本次新增與修正

- 新增黑貓小助手「墨墨」：在程式範圍內拖曳、點擊查看操作提示、右鍵互動或收起、右上角叫回。
- 啟動依電腦本機日期與時間顯示早安／午安／晚安，最後顯示「我是小助手，有操作困難請找我」。每次啟動僅問候一次，尊重先前收起設定。
- 平常每 2 秒搖尾、眨眼；閒置每 10 秒執行一次特殊動作，期間暫停小動作，完成後重新計時。
- 支援舔毛、吃飯、喝水、走路、跑步、跳躍、打滾、眨眼、玩毛線球、喵叫、生氣、趴睡；多數特殊動作加入前爪搔臉。
- 走跑使用向右的四腳側面步態與縮短鼻尖，打滾露出肚子；生氣有紅色符號、睡覺收尾並顯示 Zzz。
- 滑鼠移開貓咪／提示框不再立即關閉提示；提示框背景點擊不再穿透。
- 最小化、停用、收起與關閉時停止相關動畫；不呼叫外部 AI，不增加模型或網路依賴，不更改辨識及文件檢核規則。
- 安裝前新增四個助手模組完整性檢查，版本標示同步至程式、啟動器與兩版安裝程式。
