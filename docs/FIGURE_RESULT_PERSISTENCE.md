# 圖式辨識結果的本機保存

PDF 辨識完成及人工修改後，程式會自動保存原始 OCR 結果、修改後標號、
新增與刪除紀錄、圖號映射、方向資訊、比對清單和使用中的圖片副本。
下次匯入同名 PDF 時，自動還原完整檢核表並更新段落圖式比對。
直接選取圖片時，以同一批圖片的檔名與順序還原。

資料保存在 Windows 使用者的 `%LOCALAPPDATA%\Saint-Island_Patent_MDS\figure_recognition`。
保存不依賴原始檔案所在資料夾或轉檔暫存資料夾；程式更新後仍可使用。
保存成功或失敗由墨墨報告，不佔用圖式辨識頁的固定版面。

檔名忽略大小寫及等價 Unicode 字形，不同資料夾的同名檔案會共用最新紀錄。
若同名檔案內容變動，仍依使用者要求載入舊結果，並顯示內容已更新的提示。
按第一步會重新讀入目前選取的來源並嘗試自動轉正；第二步才進行標號 OCR，
成功後保存新版結果。若已有人工修改，第一步會先等既有結果保存完成；
保存失敗時不會替換圖片或清除檢核表。
對同一版本重新辨識時，取消或失敗會還原原有人工修改。

JSON 紀錄採原子替換；圖片以內容雜湊存放及去重。保存與讀取使用單一背景
佇列，因此快速編修後立即重匯入也會讀到最新結果。正常關閉程式時，已排入
佇列的寫入會繼續完成。損壞或缺少圖片的紀錄會顯示提示並回到一般匯入流程。

本功能開始使用前未保存的舊工作階段，無法回溯取得已遺失的人工修改。
