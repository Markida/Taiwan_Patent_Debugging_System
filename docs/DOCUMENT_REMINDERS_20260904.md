# 文件檢核新增提醒（2026-09-04）

本次依使用者確認加入以下兩條規則，保留其餘檢核規則，適用於共用文件檢核引擎。

## ABS001：中文摘要字數提醒

- 只計算「中文摘要」內文，合併其多個 Word 段落，不計章節標題、發明／新型名稱、英文摘要或代表圖符號說明。
- 同時呈現非空白字元數（含標點）與估計字數。估計方式為中文字逐字計算、連續英文／數字詞各計一字，不計標點及空白。
- 估計超過 250 字：警告；僅非空白字元數超過 250：資訊提醒，請使用者依適用計數口徑確認。
- 250 字採原則性提醒，不是自動判定文件不合格；估算法不宣稱與官方線上程式相同。
- 同一中文摘要只產生一筆字數提醒，不會逐段重複提示，不會修改原始 Word。

設計依據：[專利法施行細則第21條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?flno=21&pcode=J0070008)。

## CLM018：重複請求項提醒

- 重用現有請求項解析器，先將同一請求項跨行／跨 Word 段落的完整內文合併，再比對不同請求項。
- 忽略自己的請求項號、中文排版空白及等價全半形字元；英文詞與數值之間的空白保留詞界。
- 保留所依附的請求項號、技術數值、數量詞、否定詞、單位、大小寫、上標／下標、prime 的存在與數量。
- 只有完整正規化內文完全相同才列為警告；三個相同請求項合併為一筆並列出三個項次。空項及僅部分相似者不觸發。
- 點選提醒時，定位第一個重複項的完整內文；由使用者回 Word 確認是否為重複貼上或缺少差異。
- 不判斷法律上的權利範圍相同，也未啟用同一請求項內的重複片段偵測。表格內的請求項仍沿用既有人工確認提示，不跨欄拼接。

設計依據：[審查基準第二篇第一章，請求項簡潔性](https://www.tipo.gov.tw/tw/patents/998-66037.html)。
