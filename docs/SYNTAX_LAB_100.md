# 語法對照研究台：100件研究內測

本功能由追加100件完整文字研讀後實作；研究資料在工作區 research/yang_claim_mapping_100。研究報告與逐件筆記不等於自動檢核正確率。

## 開啟

2026-09-21起，內部測試版直接整合入口。使用平常的內測程式或專案run_app.bat即可；Run_Syntax_Lab.bat保留作為相容捷徑，不再需要環境變數。

在「專利文件偵錯」載入完整DOCX，按「語法對照（內測）」。選擇請求項與內容／實施方式查看候選原文及完整段落語境。關閉視窗即可返回。

內部測試版啟動即顯示入口，但仍在使用者點選後才執行分析。公司標準乾淨版封裝會實際移除入口、分析模組與對話框，並掃描封裝內容防止混入；不是只將按鈕隱藏。未部署至共享端、未覆蓋執行中程式。

## 不同於既有CLM019

- CLM019的原有請求項1與內容檢查維持不變。
- 研究台內容預設查項首「一種」的獨立標的，實施方式查全部項次的新增敘述。
- 不自動判定完整依附組合；未識別項首、重複項號、缺章節會提示。
- 不把候選相似度當涵蓋率；四種狀態都沒有「合格」含義。
- 候選定位支援標號輔助、所述／該、包含／包括／具有、前後置修飾及拆段的檢索；這些只是找相關文字，不宣告語義等價。
- 結構、數量作用域、跨態樣承接、公式與流程語義保留人工核對，不會把50條研究規則冒稱全數自動化。
- 圖片或表格標記為來源需核對；未做OCR公式識別。若解析器未提供影像標記，仍可能漏知抽取不完整。
- 三個候選上限可能遺漏真正相關段落；「未找到」不等於缺漏。上限1500請求項子句、每章8000來源子句，超限明示未執行。
- 純本機、唯讀；不發出網路請求，不修改DOCX或共用白名單，不新增正式錯誤。

## 回報測試結果

請附：請求項號、目標章節、未找到／找错的原句、應對照的段號；如涉及另一態樣，請保留前後段。先不要刪掉「當、未、或、至少、每一、相應」等限定字。

## 2026-09-21版本隔離驗證

- 186項測試通過：含內測分析、文件偵錯頁、原有量詞／依附規則及兩版本封裝隔離。
- 乾淨版複製後的程式實際載入GUI，確認沒有對照按鈕或開啟方法；即使外部仍有舊PATENT_MDS_SYNTAX_LAB環境變數也無法啟用，兩個模組亦不存在。
- 乾淨版封裝掃描會拒絕混入syntax_lab相關檔名或程式引用；共享UI結構變動導致移除標記失配時，封裝會停止。
- 新內測更新包：release/Saint-Island_Patent_MDS_v2.2.07_內部測試版_20260921_文件對照整合.zip。實際核對121個manifest檔案、ZIP CRC與SHA256；封裝GUI已確認不需環境變數就能顯示入口。
- 更新包不含runtime，請只套用到既有內部測試版目錄，不要套用到正式乾淨版。此工作僅產生新更新包，未執行安裝、未部署共享端，也未覆蓋舊更新包。
